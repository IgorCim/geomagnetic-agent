# Диагностика формулировки и контекста

Это отдельный эксперимент по ошибкам живого прогона на 08a04d2. Код агента,
SYSTEM_PROMPT, schemas, модель и её настройки не меняются. Новый тестовый runner
использует тот же Python-обработчик Gradio, что и прежняя автоматическая ячейка.
Проверка браузера, очереди HTTP и кнопок скачивания сюда не входит.

Сравниваются исходный запрос из сохранённого каталога и явно названные инструмент
и параметры. У каждого варианта новый чат и отдельные каталоги. Подготовка идёт
реальными сообщениями через агента. Если таблица, компоненты H/D/I или проект не
созданы, зависимый запрос получает BLOCKED_SETUP, а не фиктивный FAIL инструмента.

| Пара | Почему включена |
| --- | --- |
| derive | Просьба объяснить формулы могла переключить selector с H/D/I на DSL |
| baseline_full | Раньше модель ответила без вызова baseline |
| baseline_anomaly | Selector не предложил derived_math, модель заменила anomaly на выбросы |
| anomalies | «Статистические выбросы» ушли в get_statistics |
| list_projects | Вместо чтения диска был ответ по контексту |
| export | Модель выбрала irt/* и bou/* вместо каталогов; это также возможный дефект работы с glob |
| no_recalculate | Упоминание H/D/I в запрете могло включить обязательный расчёт в проверках запроса |
| forecast | Модель описала возможности без реального вызова |
| noaa | Реальный ответ был неправильно разделён на наблюдения, предупреждения и прогноз |
| gic_fresh | Нужна проверка gic без предыдущей метрики |
| gic_after_deltas | Та же пара запросов после deltas: влияние истории проверяется отдельно |

Итого 22 независимых чата для 11 пар плюс отдельный чат SuperMAG. Один проход
содержит 57 сообщений, включая подготовку. Не весь прежний большой прогон.
Число сообщений выводится до запуска. Новые варианты — диагностические подсказки,
а не замена обычных запросов в основном каталоге и не обучение модели.

Не включены как отдельные поломки семь зависимых A02–A08 из чата, где A01 не
создал derived; неизвестные handle после перезапуска; пустые шаблоны {PROJECT};
EEJ без научно обоснованной пары. Они не доказывают поломку соответствующих функций.
19 DSL-контролей, успешно вызванных в последнем прогоне, не запускаются заново.
Ошибка попытки вычислить F через инструмент H/D/I остаётся ошибкой аргументов;
оснований считать исходную просьбу построить H/F неправильной нет.

Один успех уточнённой версии не доказывает, что причина только в формулировке.
Обычный корректный запрос тоже должен работать. Ошибка selector или проверки
отрицания остаётся дефектом агента, даже если её можно обойти текстом.
При повторах repeats=2 или 3 порядок вариантов разворачивается; фиксированный
seed не вводится, результаты нельзя считать строгим доказательством причинности.
Формула anomaly требует проверки передачи именно текущего baseline_value.
Для gic надо сверить metric в аргументах; одного имени apply_physics_formula мало.
Отдельно проверяются отсутствие запрещённых загрузок/расчётов, файлы и числа.

SuperMAG использует логин, переданный ячейкой в состояние отдельного чата.
Логин не хранится в исходниках и скрывается в сохраняемых журналах. Отказ с
настроенным логином оценивается по фактическому ответу, а не как missing_logon.
Успех не устанавливает поддержку нового API: это проверка текущего клиента.

ISWA проверяется независимо HTTP-запросами к текущему каталогу и GetMap старого
слоя. Сохраняются URL, UTC, статус, тип, тело и SHA256. Заглушка агента не участвует.
404 подтверждает отсутствие только указанного URL. 403, таймаут или ошибка сети
не доказывают отключение NASA. Найденные слова в каталоге требуют ручного разбора:
другой продукт или статическая картинка не равны восстановленному WMS-слою.

В конце сохраняется ZIP с ответами, аргументами, журналами и CSV. Научная и
функциональная оценка остаётся REVIEW_REQUIRED; RETURNED означает только возврат
обработчика. При прерывании частичные данные и архив сохраняются.
