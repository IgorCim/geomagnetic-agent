Изменения ограничены выбором возможностей и проверками текущего запроса:
- H/D/I сохраняет инструмент расчёта вместе с загрузчиком при просьбе о формулах;
- поиск выбросов не выполняется коротким маршрутом простой статистики;
- явный запрет пересчёта исключает требование пересчёта и отклоняет такой вызов;
- формулировки «вызови», «выполни», «через» учитываются в обязательных вычислениях,
  поэтому цепочка baseline→anomaly проверяет фактическое значение текущего вызова;
- экспорт, список проектов, запрошенные NOAA/ISWA операции требуют успешного
  вызова; итог строится из записанных результатов, а не свободного заявления модели.
- экспортный glob, выбравший каталоги дат, включает их файлы через существующий
  безопасный обход проекта; irt/* больше не отбрасывает все совпавшие каталоги.
