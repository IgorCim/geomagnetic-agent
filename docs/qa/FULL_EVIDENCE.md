# Стресс и общая приёмка с SuperMAG

Запуск после обновления исходников в свежем kernel и загрузки brain.
Код агента, модель и исходные 159 карточек не меняются.

```python
from pathlib import Path
import runpy
import agent_core as ac

print('Подготовка полного прогона…', flush=True)
assert isinstance(brain, ac.LlamaBrain)
qa_root = Path(ac.__file__).resolve().parent
for name in ('demo', 'qa_download'):
    ui = globals().get(name)
    if ui is not None:
        print('Закрываю:', name, flush=True)
        ui.close()
runner = runpy.run_path(str(qa_root / 'tools/run_full_evidence.py'))
qa_result = runner['run'](brain, logon='IgorCim')
print('Все свидетельства:', qa_result['run_dir'], flush=True)
```

1. stress_300.py с логином: исходная проверка шести источников, а не допустимый
   пропуск SuperMAG. Реальный отказ не маскируется; этап получает FAILED.
2. Основные и целевые проверки: 159 карточек, 10 независимых чатов. Логин
   передаётся через окружение и существующий механизм сессионного логина.
3. Одна отрицательная проверка в новом чате без логина: ожидается missing_logon,
   отсутствие подмены источника и выдуманных данных. Сам FAILED вызова здесь
   не означает провал отрицательного теста.

Исходные запреты обращаться к другому источнику остаются в силе, даже когда
логин доступен. Наличие логина не устраняет путаницу индекса SML со станцией.

В verification/full_evidence_* находятся summary.json и три полных консольных
журнала. Вложенные chat_acceptance_* содержат ответы, вызовы, CSV и ZIP
свидетельств. Большие графики/архивы стресса остаются в stress_runs — путь
сохраняется в summary.json. RETURNED и RECORDED не означают научный PASS.
Исключение этапа не теряется и не мешает записать следующие этапы;
KeyboardInterrupt прерывает выполнение. Исходники во время прогона не обновлять.

Историческое свидетельство ошибки SML: локальный файл
verification/user_logs_20261109/1463f297-194d-4f8a-b4e4-c098b671337f.txt.
В нём корректный fetch_supermag_data(data_type=indices) завершился missing_logon,
а итоговая проверка ошибочно потребовала raw:sml:2024-09-10. Это ошибка
интерпретации/проверки запроса, не свидетельство недоступности сайта.
Рядом manifest.json содержит SHA256; исходный текст не редактировался.

Проверка обёртки: test_full_evidence.py — два теста без модели/сети,
включая продолжение после отказа стресса, изоляцию логина и восстановление
окружения/каталогов. Реальный прогон выполняется пользователем в Kaggle.
