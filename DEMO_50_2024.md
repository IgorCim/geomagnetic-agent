# DEMO 50 — 10 станций × 14–18 мая 2024

**Дата:** 2026-10-28
**Проект:** `projects/demo_storm_may2024`
**Статус:** 50/50 графиков, оба ZIP собраны, project tree не мутирован
custom-экспортом.

Это demo-набор, а не 300-chart gate. Он использует те же канонические имена,
`charts.json`, project tree и export-контракт, но содержит только 10 станций ×
5 дней.

представление, не переименование файлов.

## 3. Проверка custom-экспорта

До и после повторного `export_project(... folders=...)`:

- `project_tree` идентичен;
- SHA-256 `charts.json` идентичен;
- `manifest.json.created_at` не изменился;
- канонические имена в проекте не изменились.

То есть custom layout — экспортное представление, а не мутация проекта.

## 4. Графики

После исправления осей:

- H (nT), D (deg), I (deg) — три отдельные панели;
- подписи осей реальные, без `value`;
- H не «сплющивает» D/I;
- Plotly HTML self-contained, 1440 минут, `connectgaps=false`.

Для C-графиков supplement (11 мая) Bz (nT) и V (км/с) также разведены на
отдельные панели; заголовок показывает descriptor `sw:omni:2024-05-01`, а не
дату данных.

## 5. Partial / empty

В demo-наборе 14–18 мая все 50 ячеек полные. Отдельно проверен ожидаемый
пустой случай:

```text
ABG 2024-05-13 -> no_data
"No ABG data for 2024-05-13..2024-05-13 at any publication state
 (7 attempts failed)."
ABG 2024-05-14 -> 1440 строк, X/Y/Z/F заполнены.
```

Это не ошибка demo: 13 мая у ABG отсутствует, и агент должен показать пустую
ячейку, а не выдумывать данные.

## 6. Gradio

- `build_demo(ScriptedBrain(...))` + `launch(..., prevent_thread_lock=True)`:
  HTTP 200, страница отдаётся.
- Multi-turn session store проверен на одном `FrameStore`:
  - turn 1: `fetch_observatory_data` → `calculate_derived_components` →
    `plot_components(H)`;
  - turn 2: `plot_components(D)` по тому же
    `derived:irt:2024-05-14`, без повторного fetch;
  - оба turn `ok=true`, оба HTML существуют.
- Это проверка кода Gradio/session-store, **не** live 14B. Локально нет GPU и
  GGUF-модели; живой Qwen 2.5 14B demo нужно запускать в Kaggle/Colab, где
  модель уже проверена gate-прогоном `stress_3ffd1r21`.
