# Геомагнитный агент

Исследователь работает с геомагнитными рядами в русскоязычном чате Gradio. Например, можно запросить минутные данные Иркутска, вычислить H/D/I, сравнить два дня на графике и скачать HTML вместе с исходными таблицами. Локальная Qwen2.5-14B-Instruct выбирает операции. Python обращается к шести научным службам, выполняет расчёты и сохраняет происхождение данных.

**Запуск.** Откройте [ноутбук запуска](notebooks/run_agent.ipynb) в Kaggle, включите GPU и интернет, выполните ячейки по порядку. Для SuperMAG предоставьте секрет `SUPERMAG_LOGON`. Версия исходников выводится как HEAD. Для воспроизведения проверок есть [тестовый ноутбук](notebooks/full_test.ipynb).

**Масштаб.** 29 инструментов охватывают загрузку, анализ, построение графиков и экспорт проектов. В записанном стресс-тесте агент обработал три матрицы и создал 300 разных HTML с использованием шести источников. [Условия и результаты](docs/TESTING.md).

**Карта ISWA.** Старая интеграция использовала WMS на `iswa.gsfc.nasa.gov`. При переходе на `iswa.ccmc.gsfc.nasa.gov` команда не нашла публичного эквивалента слоя магнитных возмущений. Для этой карты штатный ответ клиента — `service_decommissioned`. Ряды Kp и Dst доступны через отдельный клиент HAPI. [Подробности](docs/AGENT.md#шесть-поставщиков-и-пределы-покрытия).

**Системный промпт.** Инструкции накапливались с раннего прототипа. Вместе со всеми схемами расчётный бюджет достигает 8190 из контрольных 8192 токенов. Обычный запрос получает выбранные схемы. План ревизии предусматривает удаление по одной инструкции и сравнение живых прогонов. [План сокращения](docs/PROMPT_REVIEW.md).

## Known issues

В основном диалоге E05 агент пропустил объяснение отказа вычислителя. В ALLOW-SML он выполнил расчёт по индексам, но при подведении итога потребовал ещё и наземную станцию SML. В коротком повторе обе задачи выполнены по существу. Для E05 сохранилась ошибочная пометка о незавершённой задаче. Отдельная проверка без логина выявила неподтверждённый HTTP 401. В одном подготовительном ответе также искажён путь проекта. [Полные журналы двух прогонов](docs/evidence/colab_transcripts.txt).
